# Data4Manu_FireEmis_Drought_Indonesia
Scripts associated with the manuscript “Fire Emissions in Degraded Peatlands Increase Twice as Fast as in Non-Peatlands Under Drought” and the dataset “A New Fire Particulate Emission Dataset for Indonesian Peatlands and Non-Peatlands, 2003–2025.”
<br>
<br>
#### The repository is organized into the following folders:
- **DroughtIndex**: Scripts for downloading and preprocessing drought indicators. 
- **Ce_Ichoku**: Scripts for calculating smoke aerosol emission coefficients for 2003–2025 following the method of Ichoku et al. (2005, 2014). 
- **FAVE(VIIRS-AHI)**: Scripts for extracting fire radiative energy information from the Fused AHI–VIIRS-based Emissions (FAVE) dataset.
- **GFAS-FAVE**: Scripts for integrating fire information from the Global Fire Assimilation System (GFAS, Version 1.2) and FAVE to generate a new fire particulate emission dataset (GFAS-FAVE) for Indonesian peatlands and non-peatlands during 2003–2025.
